# Global Support Fund

A responsive green-and-white charitable fundraising website prototype.

## Current status
- Static homepage and donation-flow preview are included in `index.html`.
- The donation form is a demonstration only. It does not collect money or process payments.
- No payment providers or cryptocurrency wallets are connected.
- Before accepting donations, confirm the organizer's legal status, publish the real campaign purpose and fund-use plan, and obtain the required approvals from payment providers and relevant authorities.

## Deploy
This is a static website. Import this repository into Vercel and deploy with the framework preset set to **Other** (or static), leaving the build command and output directory empty/default if prompted. The homepage is `index.html`.

Never put wallet seed phrases, private keys, passwords, or payment-provider secret keys in this repository.
